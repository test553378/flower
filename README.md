# おはなやさん

5歳の子どもがiPad第9世代のSafariで遊ぶ、横向き専用のWebゲームです。インストール不要で、ページを開き「はじめる」をタップすると遊べます。

全5ステージで注文どおりに花を販売し、75本を売り切ると自由制作が開きます。既存のアニメ調イラストを使用し、花束は選んだ1本ごとのPNG・包装紙・リボンを重ねて描画します。制限時間や失敗終了はありません。BGM・効果音・日本語読み上げに対応します。

ゲームの公開先：**https://ohanayasan-flower.brownbowl21.chatgpt.site**。iPadのSafariで開き、横向きにして「はじめる」をタップしてください。インストールは不要です。GitHubのファイル表示画面ではゲームは動きません。

ユーザーから公開まで自動実行する指示を受け、Sitesの静的ホスティングを使用します。GitHub接続ツールではPagesの管理操作を実行できないためです。GitHub Pagesに移す場合も、下記の設定で同じ静的ビルドを配信できます。

## iPadで起動する（GitHub Pages）

1. 実装PRを確認し、`main`にマージします。
2. GitHubのリポジトリで **Settings → Pages → Build and deployment → Source → GitHub Actions** を選びます。
3. **Actions → Publish game to GitHub Pages → Run workflow** を開き、ブランチを **main** にして実行します。自動チェックに合格したものだけが配信されます。
4. 完了後、Actionsの`github-pages`環境に表示されるURLをiPadのSafariで開きます。予定URLは **https://test553378.github.io/flower/** です（有効化前の動作は保証しません）。
5. iPadを横向きにし、「はじめる」をタップします。最初のタップをきっかけに音が再生されます。端末の音量・消音状態も確認してください。

公開PagesサイトはURLを知る人が利用できます。今回追加する公開ワークフローは手動実行のみで、PR作成や通常のpushでは公開しません。公開権限・Pagesの利用可否はGitHubアカウント側の設定によります。

## 公開前にパソコンとiPadで試す

Node.js **22以上** をインストールしたパソコンでリポジトリをクローンし、そのフォルダで実行します。

```sh
npm ci
npm run check
npm run dev
```

パソコンでは `http://localhost:4173/`。同じWi-FiのiPadでは `http://パソコンのLAN内IPアドレス:4173/` をSafariで開きます。例：PCのIPが`192.168.1.10`なら `http://192.168.1.10:4173/`。Windowsでは`ipconfig`のIPv4アドレスを確認し、Node.jsの受信をプライベートネットワークで許可します。`localhost`をiPadに入力するとパソコンには接続されません。

ゲームの利用にNode.jsのインストールは不要です。開発サーバーを動かすパソコンだけに必要です。`index.html`を直接ファイルとして開く方法はES Modules・素材取得のため対応しません。

## 遊びかた

- 注文文と音声を確認し、右側のお花を1本ずつタップ。
- 最後の1本を取り消すには「ひとつ もどす」。
- 2本以上なら「ラッピング」で紙とリボンを選び「わたす」。色は自由、包装は無料です。
- 間違えても選んだ花と注文は残ります。初回は短いヒント、2回目から必要な花の画像と本数も表示します。
- 完売したら「つぎへ」。ステージ5の後は10種類・最大10本の自由制作とコレクションが使えます。
- 「おと」でBGM・効果音・声を個別に切り替えられます。
- 「タイトルへ もどる」は確認後に進行とコレクションをリセット。音設定は維持します。再読み込みではすべて初期化します。

## 開発・配信

実行時はHTML/CSS/JavaScript ES Modulesのみ。外部API・サーバー・永続保存を使いません。`happy-dom`は開発時のDOMテスト専用です。

```sh
npm run check:assets  # 台帳・61 PNGのハッシュ、CRC、展開、寸法、透過、データ対応
npm test             # ロジック・DOM・音声APIモックの自動テスト
npm run build        # 相対URLの静的サイトを dist/ に生成
npm run preview      # ビルド後の dist/ をローカルで配信
```

`dist/`の中身を静的ホスティングに配置できます。サブディレクトリ配信にも対応します。GitHub Pagesの公開手順は上記を参照してください。
