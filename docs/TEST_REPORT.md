## 残る確認事項と実機手順

仕様の未確定8項目はユーザーの承認で解決しています。後続の公開指示を受け、Sitesで公開済みです。GitHubにも実装PRを作成します。以下は実機確認の残作業です。

2. 最初の画面から既存の高品質イラストが表示され、棚の花の種類・色、顧客の表情が見分けられるか確認する。透過輪郭や端のにじみは、台帳にある切り出し素材の品質限界も含め画像ごとに記録する。
3. 全5ステージを遊び、初回／2回目の間違い、修正、取り消し、1本販売、25色組み合わせ、会計、完売の遷移を確認する。
