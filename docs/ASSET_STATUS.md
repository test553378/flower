# 画像制作の完了状況と既存要件書の読み替え（Ver.1.1）

**2026年11月8日時点で、画像素材の初期一式は制作済みです。** このZIPの `asset_manifest.json` と個別PNGが画像素材の最新状態です。

要件定義書 Ver.1.0 第6章「画像制作後に確定」、第13章 OPEN-05「画像素材の実ファイルはこれから制作」は、**この素材パックの同梱画像については制作済み**と読み替えてください。その他の未確定要件をこの文書が承認・変更するものではありません。

このZIPにある素材は実装用の初期一式です。全身キャラクターと店内背景は個別に生成した高解像度素材ですが、多くの花、表情、リボンは生成したアトラス画像から切り出して拡大しているため、全素材が同水準の高解像度ではありません。不要な背景や隣の花が混入する問題は主要な画像で修正済みですが、輪郭の微細なにじみや低解像感などの目視確認は必要です。

不足する非画像素材：**BGM・効果音のオーディオファイル**（音源未制作。日本語注文はWeb Speech API）。

花束完成見本は任意の種類・色・本数をカバーしないため、選択された花1本画像を動的に重ね、包装紙とリボンを上に組み合わせて表示してください。

画像素材と仕様を混同しないでください。例えばお客さん数、ステージ別在庫、難易度、画面内漢字禁止はVer.1.0の確定仕様が優先です。
