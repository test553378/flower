# Codexへの実装指示：おはなやさんゲーム画像素材

このリポジトリにある `public/assets/ohanayasan/asset_manifest.json` と画像群を、既存の「おはなやさんゲーム 要件定義書 Ver.1.0」に従って使用してください。

**重要**：最初からこの高品質イラストを組み込み、絵文字や簡易SVGを代用画像として表示しないでください。画像が欠けている場合は不足を報告し、ユーザーに確認してください。仕様書で未確定とされている事項は勝手に確定しないでください。

実装要件：
1. 花の選択ボタンは `flowers/<花のキー>.png` を使い、花の内部キーと表示名、価格は `asset_manifest.json` および要件定義書からマッピングしてください。
2. `stage_inventory_confirmed` にあるステージ1〜5の在庫合計（10/12/15/18/20本）を維持してください。
3. 花束の描画は任意の組み合わせに対応するため、選択した花の画像を個別に並べて重ねてください。選択した包装紙とリボンをさらに重ね、変化を即時プレビューします。完成見本PNGで代用しないでください。
4. 正解判定に画像認識を使わず、花の種類・色・本数データの照合で処理してください。
5. 使用する画像は CSS `object-fit: contain` を基本とし、iPad第9世代横向きでも絵が切れないよう表示サイズを調整してください。
6. 背景には `backgrounds/shop_interior.png` 等を使用し、背景にUIとキャラクターを重ねてください。
7. ゲーム画面は日本語のひらがな・カタカナ中心（漢字なし）。画像に焼き付けた文字に頼らずHTMLで文字を出してください。
8. プレイヤーとお客さんは3表情（smile/happy/trouble）に切り替えられるようにしてください。
9. 音声：日本語注文は iPadのWeb Speech APIで自動読み上げ、音声オフ設定や再読み上げに対応。BGM・効果音の音源はこの画像ZIPには含まれていません。
10. Safariでの再読み込みとタイトルに戻る場合のリセット仕様を守ってください。
11. 実装後、すべての画像URLが読み込めるテストと、5ステージ完走テストを実施し、結果を報告してください。
12. まず `preview.html` で配置とサイズの目安を確認してください。これはゲーム本体ではありません。

作業完了時は動作URL、使用した画像一覧、未確定仕様、テスト結果を報告してください。


## 同梱済みドキュメント・未解決の注意
- 完全な要件書のコピー：`docs/おはなやさんゲーム_要件定義書_Ver1.0.md`（冒頭に「未確定事項あり」）。
- 必須の画像と価格・ステージ在庫の対応表：`ASSET_MAPPING.md`。
- このZIPでゲームに必要な**画像素材の初期セット**を提供しますが、**BGM・効果音の実ファイルは含まれません**。完成済みと報告しないこと。
- 仕様書13章のOPEN-01〜04等を確認するまで、該当箇所は仮決めで本実装確定しないこと。
- UIや注文には漢字を表示しない。画像素材のファイル名・文書内の漢字は問題ない。
- ユーザーが確認したキャラクターデザインから逸脱しないこと。
- 画像の一部はコンタクトシートから切り出して拡大したもの。品質上の問題があれば画像ごとに一覧で報告すること。

**画像ステータスの更新：** `ASSET_STATUS.md` を先に参照。要件書第13章 OPEN-05 の画像制作待ちは、この素材パックの個別PNGについては完了に変更された。その他の未確定事項は残る。
