# おはなやさんゲーム：画像素材パック Ver.1.1

作成日：2026-11-08  / 対象：iPad第9世代 Safari 横向き / 素材：PNG（主に透過）

## Codexへの渡し方
1. `ohanayasan_assets_codex_ready.zip` をダウンロードし、PCで展開する。
2. GitHubリポジトリに `public/assets/ohanayasan/` を作り、このZIP内の `characters/`、`flowers/`、`wrapping/`、`backgrounds/`、`ui/`、`effects/`、`bouquet_examples/`、`asset_manifest.json` をそのままコピーする。`sources/` は参照用で実装には必須ではない。
3. `CODEX_INSTRUCTIONS.md` の文章をCodexに貼り付け、要件定義書もリポジトリに配置する。画像を別途添付できるCodex環境なら素材ZIPを直接アップロードしてもよいが、Codexが参照できるリポジトリ内に配置する方法が確実。
4. Codexに画像の存在確認と実機動作テストを依頼する。

## 内容
- `characters/player`：店員の全身と3表情
- `characters/customers`：4人のお客さんの3表情×4
- `flowers`：5ステージに必要な**種類×色**の10画像（1本ずつ）
- `wrapping`：包装紙5色とリボン5色
- `bouquet_examples`：完成見本5種類（固定サンプル。注文と必ず一致するとは限らない）
- `backgrounds`：販売・タイトル・ステージクリア・自由制作・コレクション用
- `ui`、`effects`：補助イラスト
- `asset_manifest.json`：ファイル一覧と花の仕様、ステージ在庫、価格
- `preview.html`：PCブラウザで開ける組み合わせ確認ページ
- `sources`：生成画像のマスターシート（ゲーム実装では不要）

## 重要な実装上の注意
- イラストに日本語を書き込むのではなく、**HTMLテキストを重ねる**。漢字をゲーム画面に出さない。
- 花束を任意の花の組み合わせで表示するには`flowers/`の1本画像を回転・位置調整して束ね、包装紙とリボンを重ねる。サンプルの完成花束PNGを注文画像として流用しない。
- 1本売りにはラッピングをしない。2本以上はラッピングするかどうかの詳細は要件定義書の未確定事項を確認する。
- 音声素材（日本語読み上げ）はWeb Speech APIを使用する仕様のため、このZIPには録音済み音声は含まない。
- BGMや効果音の**音声ファイルは入っていない**。Codexにオリジナル素材を制作・組み込みさせる、または追加で作成する必要がある。
- 高精細の販売背景と店員全身以外は、元のコンタクトシートから切り出した画像を拡大したため、表示サイズによっては鮮明さに限界がある。素材の一部に生成上の細部崩れが含まれる可能性がある。
- 元シートに無かった白ガーベラ・紫コスモスは色を調整した派生画像であるため、実機で花の種類が判別できるか必ず確認する。
- 画面デザインや花の数量は要件定義書を優先し、アセット名や見た目から仕様を追加しない。
- iPadのSafariを実際に開いて拡大防止・音声再生・端末横向き・当たり判定を検証する。

## このZIPの対応表
- `ASSET_MAPPING.md`：花の種類と画像・ステージ在庫の対応表。
- `docs/`：作成済み要件定義書の同梱コピー。仕様の未確定事項はここで確認。
- `QA_REPORT.md`：画像枚数、破損・参照漏れチェック結果。
